Now

Adsum IoT Coder

Co-founder & Technical Lead · 2026 to present · open source, Apache-2.0

An AI coding agent for IoT firmware. It designs, writes, builds, flashes and debugs firmware on real boards. Coding agents usually read source code only. The hardest IoT bugs are in what the devices do at run time: timing between chips, protocol state, radio conditions.

  • I build the hardware-in-the-loop layer: programming devices, capturing live logs from several chips at once, testing on real boards.
  • I built its wireless debugging: radio sniffer capture, HCI traces, cellular modem traces.
  • I write the embedded knowledge the agent works from, and I own the release gate.
  • We published IoT-FirmwareDebugBench, an open benchmark that runs on physical nRF52 hardware.

Selected work

Smart parking sensors in city streets

LiveCity Systems · 2017 to 2021 · UK streets, pilot in the UAE

Battery-powered magnetometer sensors installed in public roads. I wrote the sensor driver from the datasheet, recorded real cars to design the detection, and designed the system around power: units ran for about six years on one coin cell. Sealed sensors get new firmware without being opened: a magnet triggers a short update window, and a technician sends the firmware from a phone.

Making a Bluetooth Mesh network visible

Adsum Networks · 2021 to 2024

Bluetooth Mesh gives the operator no view of the network. I built a thin layer on Zephyr's mesh stack: a controller node maps the live network (hops and signal strength per link) and sends configuration to one node or to all of them. A dashboard draws the mesh.

BLE asset tracking and gateways

Adsum Networks · 2021 to 2024

A tracking system for warehouses and industrial sites: gateway firmware, a BLE protocol designed for many tags in one place, and ThingsBoard dashboards with alerts. BLE-to-Wi-Fi gateways on ESP32 and nRF52 with an on-device web page for setup. Built and tested at small scale.

On-premise AI for factory data

Freelance · 2024 to 2026 · US telecom programme, through a UK partner

The data could not leave the site. I deployed model serving on on-premise NVIDIA GPU servers with Docker and Kubernetes, built the retrieval backend for a chatbot that answers questions over live factory telemetry, and benchmarked serving options for speed and cost.
